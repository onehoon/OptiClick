## Download & Installation

### Windows 11 — Stable

**Intel, AMD, and NVIDIA GPUs**

Download `OptiClickApp-stable-Setup.exe` from the [latest release](https://github.com/onehoon/OptiClick/releases/latest) and run the installer.

### SteamOS — Pre-release

**AMD GPUs only · SteamOS x86_64 · OptiScaler V10**

Open a terminal in **Desktop Mode** and run the following command **without `sudo`:**

```bash
curl -fsSL -A 'OptiClick/0.0.0' 'https://opticlick-public-r2.onehoon.workers.dev/opticlick-linux/installer/install.sh' | bash
```

The installer downloads the AppImage and creates a desktop launcher. Other Linux distributions have not been validated.

## Features

- Automatically discover supported games and apply game- and GPU-specific OptiScaler settings.
- Install, update, reinstall, or remove OptiScaler with a few clicks.
- Apply supported game-specific fixes and configuration automatically.
- View installation instructions and compatibility notices in the app.

## Supported Games & Support

- [Supported Game List](https://github.com/onehoon/OptiClick/wiki/Supported-Game-List)
- [Report an issue or request game support](https://github.com/onehoon/OptiClick/issues)

> [!IMPORTANT]
> Read the in-app installation notices. Third-party mods may conflict with OptiScaler, and anti-cheat policies may restrict game modifications. Use at your own risk.
